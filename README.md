# GLOW CLUB — интернет-магазин косметики

Яркий многостраничный учебный frontend-проект для Visual Studio Code.

## Страницы
- `index.html` — главная страница
- `catalog.html` — каталог с фильтрами и сортировкой
- `product.html` — карточка товара (открывается с параметром `?id=`)
- `about.html` — о бренде
- `routine.html` — интерактивный мини-подбор ухода
- `delivery.html` — доставка, оплата и FAQ
- `contacts.html` — контакты и форма
- `favorites.html` — избранное
- `cart.html` — корзина и демонстрационное оформление

## Запуск
1. Распакуй архив.
2. Открой папку `GLOWCLUB_cosmetics` в Visual Studio Code.
3. Установи расширение **Live Server** (если ещё не установлено).
4. Нажми правой кнопкой по `index.html` → **Open with Live Server**.

Можно открыть `index.html` напрямую в браузере, но Live Server удобнее.

## Функции
- адаптивная вёрстка для телефона и компьютера;
- каталог с фильтрацией по категориям и сортировкой по цене;
- отдельные страницы товаров;
- добавление/удаление товаров и изменение количества в корзине;
- избранное;
- сохранение корзины и избранного в `localStorage`;
- мини-подбор ухода из трёх вопросов;
- демонстрационные формы контактов, подписки и оформления заказа.

## Важно
Это самостоятельная статическая frontend-версия: сервер, база данных и реальная оплата пока не подключены. Формы и оформление заказа работают в демонстрационном режиме. Фотографии и веб-шрифты загружаются из интернета.

## Регистрация и личный кабинет
- `register.html` — создание аккаунта;
- `login.html` — вход;
- `account.html` — личный кабинет и выход из аккаунта.

В текущей статической версии регистрация демонстрационная: данные хранятся в `localStorage` браузера. Это удобно для показа интерфейса, но не является безопасной серверной авторизацией. Для курсового варианта с настоящей регистрацией нужно подключить Node.js/Express и БД, хранить хеш пароля и использовать серверную сессию.


## Доставка и оформление заказа
- `order.html` — оформление с контактами, адресом, датой/временем, курьером или пунктом выдачи и выбором оплаты при получении.
- Курьер — 350 ₽, пункт выдачи — 250 ₽; бесплатно от 4 000 ₽.
- Заказ сохраняется в браузере и отображается в личном кабинете при совпадении e-mail.
- Это frontend-демо: оно не отправляет заказ продавцу, не вызывает курьера и не списывает деньги. Для реального приёма заказов необходим сервер и БД.


Все фотографии в проекте заменены на изображения, предоставленные владельцем проекта. Они находятся в `assets/images/`. Чтобы заменить фото, достаточно положить новый файл в эту папку и изменить путь в HTML или в массиве `products` в `assets/app.js`.
